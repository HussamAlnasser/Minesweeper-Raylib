In this repository, I have built a Minesweeper clone. I based this on the 90s classic Windows game "Minesweeper".

This was built using C and the Raylib library, with RayGUI also used to add the GUI elements to change the difficulty and resolution.

<h3>Dependencies</h3>

<ul>
  <li>
    Install <a href="https://www.raylib.com/">Raylib</a>
  </li>
  <li>
    Download the RayGUI library <a href="https://github.com/raysan5/raygui">RayGUI</a>
  </li>
  <li>
    Make sure you have Visual Studio Code or Notepad++ installed
  </li>
</ul>

<h3>Instructions</h3>
<ol>
  <li>Make sure the value if includePath in your "c_cpp_properties.json" points to your Raylib library depending on your library. (Mine is in Windows. Thus, it is under Win32)</li>
